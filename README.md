# PolyNation

Android-приложение для интерактивного изучения стран мира. Пользователь исследует карту, узнаёт о культуре, истории и спорте каждой страны, проходит тесты и отслеживает посещённые места.

---

## Функциональность

- **Карта мира** — интерактивная карта на базе OpenStreetMap с кликабельными странами, поиском и фильтром посещённых
- **Информация о стране** — столица, флаг, население, культура, история, достижения в спорте и кино
- **Тесты и квизы** — система вопросов по флагам и столицам с рейтингом
- **Авиабилеты** — актуальные цены на перелёты от текущей геолокации через Travelpayouts API
- **Мои страны** — отметка посещённых стран, хранение на сервере
- **Аккаунт** — регистрация, вход, редактирование профиля, список посещённых стран
- **Помощник «Поли»** — анимированный маскот-проводник по приложению

---

## Помощник «Поли»

**Поли** — это глобус-водитель на маленькой машинке, дружелюбный гид по приложению.

- **Обучающий тур.** При первом запуске (и для каждого нового аккаунта) Поли проводит короткий тур по
  реальным экранам: показывает карту, поиск, геопозицию, посещённые страны, меню разделов, квизы, рейтинг и
  профиль. Тур можно пропустить в любой момент.
- **Катается по карте.** После обучения, **только на экране карты**, Поли-мобиль непрерывно и случайно
  объезжает границы экрана — по нижнему краю, вверх по бокам и по верху, разворачиваясь «туда-сюда». На других
  экранах его нет, чтобы не мешать.
- **Факты «А ты знал, что?»** Время от времени рядом с машинкой загорается значок «!» — у Поли появился
  интересный факт. Тапни по машинке, и откроется карточка со случайным фактом о стране (история, культура,
  музыка, кино или спорт) с флагом и фотографией. Факты берутся из уже загруженных данных, без обращения к сети.
  Значок «!» не теряется при переходах между экранами. Если фактов ещё не накопилось, Поли честно сообщит об этом.
- **Реакции.** Поли по-доброму комментирует открытие новой страны и отметку посещённого места, а также
  здоровается при входе.

---

## Сервер

Бэкенд задеплоен на платформе Render:

```
https://polynation-serv-backend.onrender.com
```

Сервер работает на бесплатном тарифе Render — при длительном простое уходит в спящий режим. Первый запрос после простоя может занять до 30 секунд.

> **Важно.** Если приложение не подключается к серверу или не загружает данные стран — используйте VPN с выходным узлом за пределами России. Часть внешних API (Pixabay, FlagCDN, RestCountries), а также сам хостинг Render могут быть недоступны без VPN в отдельных регионах.
